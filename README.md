# FitLog

A dark-themed workout library and daily planner. Browse exercises, check the
instructions, and add the ones you're doing today to your plan — everything
sticks around after a refresh.

## Built with

- Next.js (App Router) + React + TypeScript
- Tailwind CSS
- lucide-react icons
- Context API + localStorage for state

## Features

1. **Workout library** — all exercises pulled live from the API, sortable by duration, calories, or rating.
2. **Exercise details** — full specs and step-by-step instructions for every lift.
3. **Today's Plan** — add up to 5 workouts for the day, mark them done, remove them, watch the totals update.
4. **Saved for later** — bookmark anything you're not ready to do yet.
5. **Persisted state** — your plan and saved list survive a page refresh, no login needed.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.
